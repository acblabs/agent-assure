function Assert-NoReparseChain {
    param([Parameter(Mandatory = $true)][string]$LiteralPath, [switch]$LeafMayBeAbsent)
    $Cursor = [IO.Path]::GetFullPath($LiteralPath)

    while ($null -ne $Cursor) {
        $Item = Get-Item -LiteralPath $Cursor -Force -ErrorAction Stop
        if (($Item.Attributes -band [IO.FileAttributes]::ReparsePoint) -ne 0) {
            throw "Path chain contains a reparse point: $Cursor"

        if ($null -eq $Parent) { break }
        $Cursor = $Parent.FullName

function Assert-NoReparseTree {

The parser accepts only these lifecycle profiles: `preparation`, `kickoff-record-ready`, `kickoff-imported`, `successor-branch-initialized`, `k3-staged`, `k3-installed`, `r3-worktree`, `r3-staged`, `r3-installed`, `c3-staged`, `c3-installed`, `a3-installed`, `post-tag-final`, and `standalone`. `post-tag-final` is the connected-worktree final profile; `standalone` is the detached fresh-clone profile. No profile permits arbitrary extra package files.

Any mismatch, expiry, noncanonical JSON/base64, unexpected path, skipped/waived/deselected/not-evaluated result, altered executable, mutable Git configuration, missing receipt transfer, reused output, or topology error fails closed. C3/A3 publication, S2, release, and method admission remain unauthorized even after a successful local final verification.
