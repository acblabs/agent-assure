# agent-assure v0.6.0

v0.6.0 adds deterministic, evidence-carrying mutation checks for selected
first-party controls, strengthens release-evidence identity and replay, and
hardens the artifact, live-evaluation, and CI boundaries used to review those
results.

Highlights:

- adds persisted mutation-operator, expected-detection, mutation-result, and
  evidence-descriptor contracts under the v0.6.0 schema surface;
- adds three deterministic fixture transformations for missing material
  evidence links, bypassed required human review, and forbidden tool use;
- binds mutation results to canonical source, suite, operator, evaluator,
  method, privacy-profile, gate-profile, waiver-set, evaluation-date, and
  finding identities;
- exposes gate-profile and waiver inputs on `controls mutate`, records the
  `first_party_postcontrol` independence class, and rejects verdict-bearing
  advisory evaluator outcomes; custom evaluator identity conflicts return a
  typed incompatible result instead of escaping as an untyped exception;
- uses an unambiguous versioned finding-identity projection; exact-finding
  waivers created with an earlier development build must be regenerated;
- records authored operator provenance, implementation components, target
  controls, independence class, limitations, and immutable introduction
  commits;
- publishes each mutation output as one locked, atomically committed generation
  and rejects source/output aliases, linked output directories, and filesystem
  roots;
- makes release provenance replay the operator introduction snapshots and
  target-control digests from Git history before packaging, validates each
  replay role against its artifact contract, and rejects path and file aliases;
- preserves frozen legacy validation semantics and pins canonical release
  evidence to one exact reviewed Python runtime while normalizing persisted
  model-validation failures into value-free diagnostics;
- requires explicit current wire identity, rejects RFC 8785-unsafe integers,
  inconsistent child execution modes, and incoherent token totals before
  canonical hashing;
- strengthens persisted artifact identity, privacy-profile binding, transient-
  only live retry behavior, and OpenTelemetry exporter compatibility;
- binds live reports to suite, executed configuration, prompt, schedule,
  randomization block, provider version, adapter, pipeline, and derived cluster
  identity; duplicate observations and mismatched paired identities fail
  closed;
- prevents degenerate intervals, unbound execution configurations, and
  source-group designs that are not frozen in the protocol from producing
  confirmatory passes; paired sign-flip tests require a zero margin and strict
  boundary handling;
- preserves fixture-origin policy warnings, diffs all fail-state findings
  independently of the blocking profile, and binds drift comparability to the
  executed configuration;
- clears only owned CI outputs, rejects unsafe roots and input/output aliases,
  streams artifact hashing, prevents partial-clone lazy fetch during historical
  Git reads, and uploads only explicit generated artifacts;
- prevents stochastic or human-reviewed mutation observations from becoming
  verdict-bearing before their declared sufficiency basis is met, with
  privacy-safe diagnostics for execution failures; and
- preserves the frozen v0.5.0 and earlier schema contracts for local replay
  while emitting v0.6.0 artifacts by default.

Limitations:

- The built-in operators apply exact, privacy-filtered synthetic fixture
  transformations. A caught mutation shows that the declared detector fired
  on that transformation; it does not establish model, planner, tool-graph, or
  adversarial robustness.
- The operators are first-party post-control checks from the same codebase as
  the controls. They are not independent red-team coverage or third-party
  validation.
- Tool mutation uses exact tool identifiers, and the material-evidence mutation
  removes evidence links. Aliases, wrappers, multi-hop tool graphs, fabricated
  evidence, and semantically invalid linked evidence remain outside this
  initial three-operator set.
- Agent Assure release evidence supports reproducibility and human review. It
  does not certify safety, compliance, clinical validity, or live model quality.
